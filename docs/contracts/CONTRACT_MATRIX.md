# Cordis Kernel contract matrix

This matrix defines the semantic surface extracted at Track B0. `PUBLIC` is
caller/plugin/AgentLayer observable, `INTERNAL` is a required Kernel invariant,
`HOST` constrains an execution host, `WIRE-CANDIDATE` may inform a future wire
schema, and `PLACEHOLDER` names an intentionally incomplete concept. Source and
test names are authorities; links to implementation mechanisms are explanatory,
not contracts.

## Inventory

The matrix contains the original 55 B0 contracts plus 14 B2.0 Host/Wire
contracts and one B2.1A preparation contract: 70 total, comprising 35 `PUBLIC`, 12 `INTERNAL`, 11 `HOST`, 10
`WIRE-CANDIDATE`, and 2 `PLACEHOLDER`. The original B0 readiness inventory was
33 `READY`, 11 `INTERNAL-ONLY`, 4 `PARTIAL`, and 7 `NO`; B2.0 design rows remain
`NO` until B2.1/B2.2 supplies executable ProcessHost evidence. The two-letter
`GC` prefix is intentional; inventory tooling must not assume every Contract ID
has three letters.

## Explicitly non-contractual

- `parking_lot::Mutex`/`RwLock` choice and guard layout.
- Packed `AtomicUsize`, memory ordering implementation, cache-line alignment and
  GenerationExecution representation.
- Registry maps, arena implementation, selector object, cache capacity, FIFO
  eviction and fast-path structure.
- `FiberMutable`/`RuntimeInner` field layout and Rust `Arc` mechanics.
- Worker scheduling implementation, Tokio task placement and exact callback
  structure where the observable ownership contract is preserved.
- GC full-scan versus future reclaim queue implementation.
- Rust enum discriminants, struct layout and pointer representation as wire ABI.
- Benchmark throughput/latency numbers; they are regression evidence, not SLA.

## Durability boundary

“Durable” disposal/shutdown completion means immutable Runtime-owned in-process
convergence truth that survives observer drop and registry GC. Cordis v2 has no
checkpoint/replay store and does not persist lifecycle execution across process
crash. It is not a whole-execution durable workflow runtime.
